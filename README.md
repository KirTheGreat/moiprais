# Мой Прайс — прототип 1.0

Простой Android-first прототип калькулятора клининговых услуг. Сделан на HTML/CSS/JavaScript без платных библиотек и серверов.

## Что работает
- Выбор типа уборки.
- Площадь и скидка.
- Дополнительные услуги.
- Редактирование и сохранение собственных цен.
- Автоматический пересчёт.
- Сохранение последних 30 расчётов на устройстве.
- Создание сметы через системную печать: выберите «Сохранить как PDF».

## Как открыть на компьютере
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Проверьте калькулятор, цены, сохранение расчёта и печать.

Для проверки service worker и установки PWA нужен HTTPS или localhost. При простом открытии файла некоторые браузеры не включат установку и офлайн-кэширование.

## Как установить на Android бесплатно
1. Опубликуйте содержимое папки на HTTPS-хостинге. Для статического прототипа можно использовать GitHub Pages.
2. Откройте адрес сайта в Chrome на Android.
3. Откройте меню Chrome и выберите «Установить приложение» или «Добавить на главный экран» (название зависит от версии).
4. Запустите приложение с главного экрана.

## Как бесплатно опубликовать через GitHub Pages
1. Создайте аккаунт GitHub.
2. Создайте новый публичный репозиторий, например `moi-prais`.
3. Загрузите в корень репозитория файлы `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`.
4. Откройте Settings → Pages.
5. В разделе Build and deployment выберите Deploy from a branch, ветку `main` и папку `/root`, сохраните.
6. Дождитесь публикации и откройте выданный HTTPS-адрес на Android.

Интерфейс GitHub может меняться; актуальную инструкцию см. https://docs.github.com/pages

## Как формируется PDF
Кнопка «Создать PDF-смету» открывает окно печати браузера. На Android выберите «Сохранить как PDF». На компьютере выберите системный принтер PDF. Это не отдельный PDF-файл, создаваемый сервером.

## Важные ограничения прототипа
- Данные хранятся только в локальном хранилище браузера на данном устройстве.
- Очистка данных браузера может удалить историю и цены.
- Пока нет облачной синхронизации, регистрации, оплаты и резервного копирования.
- Цены в примере демонстрационные: владелец должен заменить их на свои.
- Перед коммерческим запуском нужны тестирование, политика конфиденциальности и проверка требований к обработке персональных данных.
