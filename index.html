«Заработано» учитывает полную сумму выполненных заказов по дате заказа. «Получено» — только реальные платежи по датам поступления. В расходы включены обычные расходы и начисленная зарплата за выполненные работы. Денежный поток показывает поступления минус внесённые расходы. Начисленная зарплата уменьшает финансовый результат в месяце завершения работы. Себестоимость рассчитывается по сохранённому составу заказа и отдельно используется для оценки прибыльности заказов.

Доходы и расходы

Состав отчёта

В отчёте отдельно показаны заработанная выручка по выполненным заказам и фактически полученные платежи по датам оплат. Финансовый результат = заработано минус внесённые расходы; денежный поток = получено минус внесённые расходы; начисленная зарплата учитывается отдельно в финансовом результате. Себестоимость показывается отдельно и используется для расчёта прибыли по каждому заказу, чтобы не вычитать её повторно.

Прибыльность выполненных заказов

Себестоимость берётся из сохранённого состава заказа. Для старых заказов без сохранённой себестоимости будет показан ноль.
