Как читать показатели

Заработано — полная сумма выполненных заказов по дате заказа. Получено — платежи по дате поступления.

Финансовый результат учитывает обычные расходы и начисленную зарплату. Себестоимость заказов показывается отдельно и не вычитается повторно.

Денежный поток пока вычитает обычные расходы. Фактические выплаты зарплаты отдельно не регистрируются, поэтому начисления в него не включены.

Остаток по выполненным заказам — неоплаченная часть заказов, завершённых в выбранном месяце.

Доходы и расходы

Состав отчёта

В отчёте отдельно показаны заработанная выручка по выполненным заказам и фактически полученные платежи по датам оплат. Финансовый результат = заработано минус внесённые расходы; денежный поток = получено минус внесённые расходы; начисленная зарплата учитывается отдельно в финансовом результате. Себестоимость показывается отдельно и используется для расчёта прибыли по каждому заказу, чтобы не вычитать её повторно.

Прибыльность выполненных заказов

Себестоимость берётся из сохранённого состава заказа. Для старых заказов без сохранённой себестоимости будет показан ноль.

Состояние данных

Все данные сейчас хранятся локально в этом браузере. Для переноса на другое устройство используйте резервную копию.
